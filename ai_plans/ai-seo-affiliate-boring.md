# Business Kit: AI SEO Affiliate in Boring Niches

## Problem
Buyers search boring, high-intent keywords every day ("commercial sink drain", "ISO medical gloves", "industrial pressure washer parts") but the existing content is thin, outdated, and unhelpful — so the affiliate commissions go begging.

## Audience
You, as the autonomous operator. The actual readers are purchasers with clear buying intent in unglamorous verticals (plumbing supplies, medical consumables, workshop tools, safety equipment).

## Offer
An AI content machine that researches 50-100 long-tail buying-intent keywords per month, writes + human-style-edits comparison and review articles, publishes them to a WordPress site, and monetizes via Amazon Associates and niche affiliate networks. The "boring" angle is the moat: thin competition, high commercial intent.

## Pricing
$50-$2000/month in affiliate commissions. Pricing psychology: this is pure margin once running — anchor on the cost of one missed commission month, not on effort. Reinvest the first $500 into a second boring site.

## Channels
- Google organic SEO (primary)
- Pinterest (evergreen pins to articles)
- Reddit niche subs (genuine help, link when relevant)
- YouTube Shorts repurposing top articles into 30s explainers

## Free Tool Stack (0 budget)
- Hermes (research + drafting)
- WordPress.com free tier (or self-hosted)
- Ahrefs free trial / Google Keyword Planner (free)
- Amazon Associates (free to join)
- Google Search Console (free)

## 7-Day Launch Plan
- **Day 1** — Pick one boring vertical (e.g. "commercial kitchen equipment"). Register a domain + free WordPress.
- **Day 2** — Use Hermes to extract 100 long-tail buying-intent keywords from forums + Amazon autocomplete.
- **Day 3** — AI writes 10 pillar + 20 supporting articles. Set internal links.
- **Day 4** — Apply to Amazon Associates; add affiliate disclosure.
- **Day 5** — Publish 15 articles; submit sitemap to Search Console.
- **Day 6** — Build 20 Pinterest pins (AI-generated text + free Canva). Schedule.
- **Day 7** — Write a Reddit value comment in the niche; measure zero traffic yet but lock the system.

## AI Execution
An AI agent runs this end-to-end: it pulls keyword ideas from search autocomplete and forums, drafts and self-edits articles with a consistent tone, publishes via the WordPress REST API, inserts affiliate links from a product table it maintains, builds internal links, and weekly checks Search Console for crawling issues. It spins up a second vertical once the first crosses $100/month. A human only reviews payouts.

## One-Line Pitch
A content machine in boring niches that earns while you sleep.
