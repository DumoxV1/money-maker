# Business Kit: AI Vertical-SaaS UI Asset Kits

## Problem
Indie SaaS and no-code builders in narrow industries still need polished product interfaces, but generic icon libraries rarely cover domain actions such as recording an equipment fault, quarantining a lab sample, approving a field-service variation, or scheduling a property inspection. Hiring an illustrator is expensive, while raw AI vectors arrive with inconsistent geometry, unsafe SVG markup, weak naming, duplicate concepts, and no implementation metadata.

## Audience
Indie SaaS founders, no-code builders, and small product agencies serving quiet verticals such as equipment inspection, laboratory tracking, field-service quoting, property maintenance, specialty logistics, and other workflow-heavy B2B software.

## Offer
A downloadable, production-checked asset kit built around one vertical workflow. Each kit contains 40-80 original SVG icons, 8-12 coordinated empty-state illustrations, outline and filled variants where useful, light/dark and `currentColor` support, semantic filenames, design-token JSON, PNG previews, suggested accessible labels and alt text, a contact sheet, implementation notes, a provenance manifest, and a plain commercial-use license. The differentiation is not raw image generation; it is coherent coverage of the customer's actual workflow plus automated technical QA.

## Pricing
Charge €19 for a focused starter kit, €39-59 for a complete workflow kit, or €129 for a multi-workflow vertical bundle. Offer a five-icon sampler with the same validation report and license so buyers can test compatibility before purchasing. Sell updates to existing buyers as part of the product rather than a manual customization promise.

## 7-Day Launch Plan
- **Day 1** — Choose one boring vertical from public, terms-compliant demand signals. Build a workflow vocabulary of 40-60 generic concepts, then exclude trademarks, vendor-specific interface copies, customer data, protected characters, and concepts already covered by the current catalog.
- **Day 2** — Create a machine-readable style contract for canvas, grid, viewBox, stroke width, corner radius, palette, fill behavior, complexity budget, variants, forbidden elements, filename rules, and required metadata. Generate several original style directions and select one by automated consistency scoring.
- **Day 3** — Generate the full icon and empty-state set through the approved provider. Normalize paths, dimensions, colors, titles, filenames, and token references. Regenerate any asset that fails the style contract or appears semantically ambiguous.
- **Day 4** — Run safety and quality gates: parse every SVG as XML, reject scripts and external references, sanitize metadata, verify viewBoxes and path budgets, detect near-duplicates, render every variant, compare stroke and palette consistency, and test light/dark and `currentColor` behavior.
- **Day 5** — Produce semantic labels, optional alt-text suggestions, design-token JSON, implementation notes, provenance and license manifests, contact sheets, raster previews, checksums, and a deterministic ZIP. Validate the archive from a clean extraction directory.
- **Day 6** — Create the storefront listing with exact asset counts, screenshots, technical specifications, AI disclosure where required, license scope, refund terms, and a free compatibility sampler. Connect checkout, delivery, versioning, receipts, and support intake.
- **Day 7** — Publish useful workflow maps and validation demos, submit one rules-compliant launch post per relevant community, send low-volume personalized outreach only to businesses with a clearly relevant public product, and feed structured compatibility requests into the next automated release.

## AI Execution
A scheduled agent collects only public, permitted demand signals and clusters repeated workflow language without copying a competitor's interface or proprietary taxonomy. It selects a narrow opportunity, creates a constrained style and concept specification, checks every concept against trademark and duplication blocklists, and calls a commercial-rights vector-generation provider. The pipeline sanitizes and normalizes each SVG, generates variants and previews, validates XML and archive safety, removes external references, enforces viewBox and path limits, measures visual consistency, finds semantic or visual duplicates, checks light/dark contrast and `currentColor` rendering, and regenerates failures. It then writes implementation metadata, labels and alt-text suggestions, creates the license and provenance manifest, packages a deterministic release, lists it through a supported storefront API, fulfills downloads, handles routine support from the manifest, and converts recurring requests into versioned updates. Prospecting, checkout, production, QA, delivery, updates, and reporting are digital and schedulable; no person has to illustrate assets, attend calls, ship anything, or perform recurring fulfillment.

## Legal and Quality Guardrails
- Generate original, generic workflow concepts only. Do not imitate a named designer, copy a product's iconography, trace marketplace assets, or use brand names, logos, protected characters, celebrity likenesses, or confidential customer screens as prompts.
- Before each production run, verify that the generation provider and every input source grant the commercial rights required for the planned sale. Store provider, model, prompt, timestamp, source, and applicable license records; never promise exclusivity or copyright ownership beyond what can be supported.
- Follow current marketplace AI-content and disclosure rules. If a channel prohibits generated assets or automated listings, do not use it.
- Treat labels and alt text as implementation suggestions, not an accessibility certification. Run objective checks, disclose their scope, and avoid claiming WCAG compliance without context-specific testing.
- Parse and sanitize all SVGs; reject scripts, event handlers, embedded remote content, external references, malformed XML, hidden tracking elements, and files that exceed the documented complexity budget.
- Require reproducible render, duplicate, naming, token, manifest, checksum, malware, and clean-extraction tests before release. Never describe an unchecked generation as production-ready.
- Use truthful, low-volume, opt-out outreach and respect anti-spam law, robots directives, platform terms, community rules, rate limits, and suppression requests.
- Keep customer uploads out of the standard product. If authorized private inputs are ever accepted, isolate tenants, minimize retention, encrypt data, and provide export and deletion controls.
