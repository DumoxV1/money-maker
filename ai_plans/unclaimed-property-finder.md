# Business Kit: AI Unclaimed-Property Finder

## Problem
People are owed forgotten money — uncashed checks, security deposits, insurance payouts — across 50 state databases, but nobody searches all of them.

## Audience
Consumers owed money; heirs; small businesses with old vendors/employees.

## Offer
An AI that queries NAUPA/MissingMoney state databases by name, scores likely matches, and files claims for a 10-20% contingency fee.

## Pricing
10-20% of recovered (contingency — client pays nothing unless paid). Pricing psychology: pure upside, so "yes" is automatic.

## Channels
- Reddit r/personalfinance
- Facebook unclaimed-money groups
- SEO site "find my money in [state]"
- Nextdoor

## Free Tool Stack (0 budget)
- NAUPA / MissingMoney search (scrape/API)
- Notion (match tracker)
- Calendly (intake)
- Stripe (payout split)

## 7-Day Launch Plan
- **Day 1** — Map the 50-state search endpoints; build the query logic.
- **Day 2** — Write the intake (name + states lived in).
- **Day 3** — Post in r/personalfinance: "you may be owed $ — I'll check free."
- **Day 4** — Landing page on GitHub Pages (finder form).
- **Day 5** — Cold-post in 5 Facebook groups.
- **Day 6** — Run 3 pilot searches; prep claims.
- **Day 7** — Launch a free weekly "states with unclaimed money" newsletter.

## AI Execution
An AI agent queries state unclaimed-property databases by client name, scores matches, autofills claim forms via browser automation, and tracks deadlines. Contingency-only; a human handles ID-verification steps the state requires.
